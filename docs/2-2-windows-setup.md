# Windows Setup

Since we have removed a lot of the unnecessary steps using Rufus (or the unattend script made by it), the installation will be much simpler.

If you got the installation to start in the last part, you should now find a language selection screen. I'll leave this choice up to you, and there's no harm in picking whatever suits your needs.

![Select Windows Language](../../images/2-2-setup-select-language.png)

Similarly, you'll have to select your keyboard layout for this installation. It is only for the installation, as you'll get the chance to modify or add other keyboard layouts later on.

![Select Installation Keyboard Layout](../../images/2-2-setup-keyboard-selection.png)
