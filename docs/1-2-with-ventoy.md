## Download AnyBurn
Ventoy is a rather convenient tool if you can keep a flash drive preinstalled with it. But it doesn't allow you to make changes to the ISO as Rufus offers. Since we need those changes, we will be modifying the ISO a little bit with AnyBurn before touching Ventoy.
